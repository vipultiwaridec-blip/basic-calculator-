# 🧮 Calculator

A simple and responsive **Arithmetic Calculator** built using **HTML, CSS, and JavaScript**.

This project is designed to perform basic mathematical operations with a clean and user-friendly interface. It is a beginner-friendly web development project that demonstrates the use of HTML for structure, CSS for styling, and JavaScript for functionality.
